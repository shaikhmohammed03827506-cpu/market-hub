## After publishing the website

1. Open the website's **Admin** page and sign in.
2. Select **Products**.
3. Press **Import PDF catalogue** once.
4. Wait for the success message. Do not close the page during the import.

The import can safely be run again later: it updates the same product codes instead of adding duplicates.

Keep this website folder private while it contains the `.env` file. The `.env` file holds your private server settings and must never be uploaded as a public file.
